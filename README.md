VELMARA — The Lantern Harbour: a travel poster for a place that doesn't exist. A harbour town on a floating islet where paper lanterns are launched onto the tide every dusk, watched over by one red-banded lighthouse. Drawn entirely in code with Pillow — dusk-indigo sky, amber horizon, lantern sea, no fetched images, no randomness. Run twice and the bytes match.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Output: `out/entry.png` (768x1024, under 1 MiB).
